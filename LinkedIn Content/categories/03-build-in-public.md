# Card 3 — Build-in-Public

## Reader outcome
The reader trusts the builder a little more, because they were shown the result AND its cost.

## Available moves
- **Bare-result opening** — the number or event, plainly, no wind-up. The fact is the drama. Use whenever a real result exists; if none exists, don't post.
- **Honest complication** — what broke, strained, or cost. Use almost always; the victory lap without a wound is the canonical loser here. Skip only when nothing went wrong AND the result is extraordinary.
- **Anatomy breakdown** — labeled mini-sections on what drove the result, with named people where due. Use when the mechanism is instructive.
- **Forward-motion close** — gratitude + what's next + optional soft invitation for a specific reader type.

## Failure modes
- Asking before giving (feedback requests framed as updates).
- Vague progress with no verifiable number.
- Hype punctuation doing the work the number should do.

## Length prior
Bimodal: under ~40 words (scorecard mode) or 140–320 words (build log). The middle is weakest.
