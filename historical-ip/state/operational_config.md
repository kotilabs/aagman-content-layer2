# Historical Storytelling IP — Operational Config

## Cadence

- One deep essay per week.
- Signal digest generated once per week.
- Research and drafting mid-week.
- Review and approval before weekend.

## Surfaces

Default surfaces for every story:
- Substack blog (mandatory)
- X thread
- LinkedIn carousel (promotional)
- Instagram carousel (promotional)
- Infographic concepts

Operator can opt out of any surface per story.

## Automation depth

Full operator gates:
1. Signal digest approval
2. Research artifact approval
3. Blog first draft approval
4. Fact-check review
5. Revised blog approval
6. Thread/carousel/infographic approval
7. Historical reviewer report
8. Social teaser approval
9. Final approval

## Voice

Single voice guide for all writing: `voice/historical_voice_base.md`.

Contains:
- Core identity and tone discipline
- Substack / long-form essay rules
- X thread rules
- Carousel rules (LinkedIn + Instagram)
- Social teaser rules
- Pre-publish checklist

## File naming

Use `story-{story-id}` prefix for all artifacts.

## Topic memory

`state/covered_topics.json` is the single source of truth for covered stories. The signal generator must read it before proposing ideas.

## Git policy

No commits without explicit operator permission.
